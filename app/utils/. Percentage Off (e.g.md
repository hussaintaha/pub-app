. Percentage Off (e.g., 20% off)
Automatic Trigger
Mutation: discountAutomaticBasicCreate Input Type: DiscountAutomaticBasicInput Key Configuration:

Set customerGets.value to DiscountPercentage with percentage value
Use minimumRequirement for cart conditions
Configure startsAt/endsAt for timing
Set customerSelection for targeting specific customers
Discount Code Trigger
Mutation: discountCodeBasicCreate Input Type: DiscountCodeBasicInput Key Configuration:

Include code field for the discount code
Set customerGets.value to DiscountPercentage
Configure usageLimit and appliesOncePerCustomer
Use same targeting options as automatic
Cart Conditions Trigger
Mutation: discountAutomaticBasicCreate (same as automatic) Special Focus: Use minimumRequirement extensively

subtotal for minimum purchase amount
quantity for minimum item count
Combine with customerGets.items to target specific products/collections

5. Tiered Percentage (Spend More Save More)
All Trigger Types
Limitation: Not directly supported by single mutations Workaround Solutions:

Option 1 - Multiple Basic Discounts:

Create multiple discountAutomaticBasicCreate or discountCodeBasicCreate mutations
Each with different minimumRequirement.subtotal values
Higher minimum requirements get higher percentage discounts
Use combinesWith to prevent stacking
Option 2 - Shopify Functions (Plus Only):

Use discountAutomaticAppCreate or discountCodeAppCreate
Implement custom tiered logic in the discount function
Requires Shopify Plus plan and custom development
Option 3 - Third-Party Apps:

Install apps from Shopify App Store that support tiered discounts
Apps handle the complex logic internally

Implementation Notes
Customer Segments: Many advanced targeting features require pre-created customer segments using Shopify's customer segmentation tools or GraphQL customer segment mutations.

Shopify Functions: Complex discount logic often requires Shopify Functions (Plus feature) with app-based discount mutations.

Combination Rules: Use combinesWith input to control how discounts interact with other active discounts in the store.

Testing: Always test discount mutations in a development environment before deploying to production stores.
